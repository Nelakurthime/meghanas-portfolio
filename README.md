## 🚀 How to Run Locally

### Option 1: Direct Double Click (Zero Setup!)
Simply open `index.html` in any web browser (Chrome, Edge, Firefox, Brave, Safari).

### Option 2: Using Node.js Local Server
In this directory, run:
```bash
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 1-Click Deployment Options

### Deploy to Vercel
1. Push this folder to a GitHub repository (e.g. `Nelakurthime/portfolio`).
2. Go to [vercel.com](https://vercel.com) and import the repository.
3. Deploy! No build steps required.

### Deploy to GitHub Pages
1. Go to repository settings on GitHub.
2. Under **Pages**, select branch `main` and root directory `/`.
3. Save and your portfolio will be live at `https://Nelakurthime.github.io/portfolio/`.
